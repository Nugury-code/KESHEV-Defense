# 케셰브 최종 커밋 재현 기록과 릴리스 기록 (22단계)

이 문서는 학생(원석연)이 직접 작성한 재현 기록입니다. `docs/STUDENT_RUNBOOK.md`(21단계 실행 설명서)와 함께 읽습니다. 이 문서는 이 저장소의 제공 문서를 수정하지 않고 새로 추가한 학생 문서입니다.

## 0. 이 기록을 읽는 법

| 구분 | 뜻 | 이 문서의 표기 |
|---|---|---|
| 원문 확인 | 저장소의 파일 내용을 읽어서 확인함. 명령을 실행한 결과가 아님 | 「원문」 |
| 학생 진술 | 내가 PC에서 직접 하고 본 것을 적은 것. 서버가 확인한 것이 아님 | 「진술」 |
| 시연 | 예제(demo) 모드나 연결 없음 화면을 보여 준 것. 실제 시스템 연결 성공이 아님 | 「시연」 |
| 실제 실행 검증 | 실제 접근 제어·XDR 시스템과 AI 연결까지 성공을 확인한 것 | 이 문서에는 해당 항목 없음 |
| 미확인 | 하지 않았거나 결과를 보지 못함 | 「미확인」 |

AI의 원문 검토는 이 기록을 읽고 코드·문서와 맞는지 보는 것이며, 앱이 실행되어 성공했다는 증명이 아닙니다. 22단계 통과가 되어도 원문 검토 기준의 수료이고, 실제 운영 인증이나 v1.0 자동 인증이 아닙니다.

| 대상 | 보존·백업 | 복원 | 제한 |
|---|---|---|---|
| 내가 작성한 코드와 문서(`student/`, `docs/`) | 커밋하고 GitHub 원격에 푸시. 이전 커밋들이 기록으로 남음 | 새 폴더에 `git clone`, 또는 필요한 커밋으로 `git checkout`. 기록을 지우는 `git reset --hard`는 쓰지 않음 | 푸시하지 않은 변경은 이 방법으로 보존되지 않음. 저장소는 GitHub의 가용성에 의존 |
| 제공 파일(`src/`, `public/`, `tools/`) | 같은 저장소에 함께 커밋됨 | 같은 방법 | 제공 파일의 업데이트는 운영자가 적용하며 내가 직접 하지 않음 |
| 계정 연결 설정·자격 보관소 | 프로젝트 밖의 사용자 폴더에 프로젝트 폴더 경로별로 따로 보관됨. 저장소에 넣지 않으며 백업하지 않음 | 복원하지 않고, 새 환경에서 앱의 「계정 연결」 승인을 새로 진행 | 보관소 내용은 내가 열어 보지 않았음. 폴더 경로가 바뀌면 새 보관소가 만들어져 기존 승인을 이어받지 못함 |
| 앱을 실행하며 읽는 PC 상태·진단 값 | 화면에 표시되는 것을 확인함. 별도로 저장하는 설정은 내가 읽은 범위에서 찾지 못함 | 해당 없음 | 코드 전체를 읽은 확인은 아님(미확인) |

## 9. 버전과 지원 범위, 누락·미해결

| 항목 | 내용 |
|---|---|
| 앱 버전 | 시작 틀 0.2.21 기반. 검증 중인 버전(실제 연결 미완료 항목이 남아 있음) |
| 지원 환경 | 재현한 환경은 Windows 11 Pro, PowerShell 5.1, Node.js v24.21.0 하나뿐입니다. 다른 OS·macOS·Linux는 시도하지 않았고 지원 여부는 미확인입니다. Node.js 22 미만·25 이상은 실행 도구가 멈춥니다(원문) |
| 미해결 1 | 접근 제어·XDR 시스템(SDP)의 실제 연결과 판정·기록 조회 성공은 확인하지 못함 |
| 미해결 2 | 계정 연결과 AI 연결 완료를 확인하지 못함. 이전 폴더에서는 점검 결과가 `ON_AI_PROVISIONING_PENDING`이었고, 새 폴더에서는 시도가 `OUTCOME_UNKNOWN`으로 끝남 |
| 미해결 3 | AI 설명(18단계)·보안 조치(19단계)의 성공 화면은 본 적이 없음. 보안 조치를 실제로 처리하는 연결(19단계 실집행)은 아직 준비되지 않음 |
| 미해결 4 | 13~16단계 제출 커밋과 모든 단계의 통과 시각은 기록이 없음 |
| 미해결 5 | `-Port`·`-Background`·`-Demo`·`-NoNativeHost` 옵션과 설치형 패키지(`npm run package-app`)는 사용하지 않음 |
